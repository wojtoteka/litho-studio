PAKOWANIE
  npm run package:win            (na maszynie z Windows)
  npm run package:linux          AppImage
  npm run package:linux:deb      .deb

WERSJA
  npm run version:set 1.0.2      podbija wersję i mówi, co dalej

  Numer wersji jest zapisany TYLKO w package.json ("version"). Wszystko inne
  bierze go stamtąd automatycznie:
    - electron-builder  -> nazwy plików w release/ i metadane pakietu
    - app.getVersion()  -> "masz wersje X" przy sprawdzaniu aktualizacji
    - pasek stanu       -> window.litho.appVersion (przez preload)

AKTUALIZACJE
  Przy kazdym uruchomieniu aplikacja pyta https://wojtoteka.ovh/api/litho/releases
  o verL (Linux) / verW (Windows). Jesli tam jest nowszy numer niz biezaca wersja:

    1. wyskakuje okno "Dostepna jest nowa wersja" (nowy numer, Twoja wersja,
       system, adres strony) z przyciskami "Pobierz" i "Pozniej",
    2. po zamknieciu okna zostaje pasek na gorze z tymi samymi danymi
       i przyciskami "Pobierz" / "Ukryj".

  "Pobierz" NIE pobiera zadnego pliku - otwiera tylko
  https://wojtoteka.ovh/inne/litho/ w przegladarce uzytkownika, a plik
  (AppImage / .deb / Windows) wybiera i instaluje on sam.
  "Pozniej" i "Ukryj" dzialaja tylko do konca sesji - przy nastepnym starcie
  aplikacja zapyta znowu.
  Brak internetu = brak okna i paska, bez zadnego bledu.
